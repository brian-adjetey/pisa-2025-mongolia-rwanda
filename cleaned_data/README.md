# Cleaned analysis data

Run Section 10 of `PISA_2025_Mongolia_Rwanda_Insight_Report.ipynb` after running the notebook from top to bottom. It creates:

- `student_analysis_clean.parquet`
- `school_analysis_clean.parquet`

These are the analysis-ready cleaned datasets used by the final project. Commit both files here after they are generated. If the student parquet exceeds GitHub's browser-upload limit, add it with Git from the command line (GitHub permits ordinary repository files up to 100 MB). If it exceeds 100 MB, use Git LFS or split the file by analysis group.
